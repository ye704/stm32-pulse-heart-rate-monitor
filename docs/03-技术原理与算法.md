# 技术原理与算法

> 面向面试复盘的原理说明：**为什么要这么设计**、**代码里对应哪几行**、**参数怎么来的**。

---

## 1. 传感器原理：PPG 光电容积脉搏波

Pulse Sensor 是反射式光电传感器：绿光 LED 照射皮肤，光敏元件接收反射光。
心脏每收缩一次，末梢血管血容量增加 → 血液对绿光吸收增强 → 反射光减弱 → 输出模拟电压出现一个周期性起伏。

| 特性 | 说明 |
| --- | --- |
| 输出信号 | 模拟电压，随血容量周期性变化，典型范围约为电源的 20%–80% |
| 信号特征 | 存在明显的"主波峰"和随后的"二重脉（dicrotic notch）"小波 |
| 直流分量 | 因皮肤、压力、肤色不同而漂移 → **这是必须用自适应阈值的原因** |
| 采样要求 | 生理信号带宽 < 5 Hz，按奈奎斯特采样 10 Hz 即可，本项目取 500 Hz 留足余量 |

## 2. 采样与时基：TIM3 + ADC1

### 2.1 参数计算

| 参数 | 取值 | 说明 |
| --- | --- | --- |
| 系统时钟 | HSI 16 MHz | 未启用 PLL，`SystemClock_Config` 中 `PLLState = RCC_PLL_NONE` |
| TIM3 预分频 | PSC = 15 | 计数时钟 = 16 MHz / 16 = 1 MHz |
| TIM3 自动重装 | ARR = 1999 | 溢出周期 = 2000 / 1 MHz = **2 ms** |
| 等效采样率 | **500 Hz** | 每 2 ms 采样一次 |
| ADC 分辨率 | 10 位（0–1023） | `ADC_RESOLUTION10b`，中点约为 512 |
| ADC 采样时间 | 15 周期 | `ADC_SAMPLETIME_15CYCLES` |
| 触发方式 | 软件触发 | 每次中断里 `HAL_ADC_Start()`，非定时器硬件触发 |

### 2.2 中断服务函数的主干逻辑

```c
void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim)
{
    Signal = HAL_ADC_GetValue(&hadc1);      // 1. 读上一次/本次转换结果
    sampleCounter += 2;                     // 2. 毫秒时基（2 ms 加 2）
    Num = sampleCounter - lastBeatTime;     // 3. 距上次心搏的毫秒数
    HAL_ADC_Start(&hadc1);                  // 4. 启动下一次转换
    ...                                     // 5. 心搏检测（见第 3 节）
}
```

**为什么用 `sampleCounter += 2` 而不是读系统滴答？**
因为心搏间期的单位是毫秒，而采样周期已知恒为 2 ms，
用"采样次数 × 2"得到的时间与采样本身同源，不受其他中断或主循环延迟影响。

## 3. 心率检测算法

算法源自 PulseSensor 开源项目，核心是**"三变量跟踪 + 自适应阈值"**的心跳判定状态机。

### 3.1 状态变量

| 变量 | 初值 | 含义 |
| --- | --- | --- |
| `Signal` | — | 当前采样值（0–1023） |
| `P` | 512 | 当前脉搏波的**峰值** |
| `T` | 512 | 当前脉搏波的**谷值** |
| `thresh` | 512 | 判定阈值（动态） |
| `amp` | 100 | 上一拍的峰谷幅度 `P - T` |
| `Pulse` | false | 当前是否处于"波峰已过、波谷未到"的高电平段 |
| `IBI` | 600 | Inter-Beat Interval，两次心搏间隔（ms） |
| `rate[10]` | — | 最近 10 次 IBI，用于滑动平均 |
| `QS` | false | "检测到一次心搏"标志，由 ISR 置位、主循环清零 |
| `firstBeat` / `secondBeat` | true / false | 启动阶段丢弃不可靠的前两拍 |

### 3.2 检测流程

```
        ┌─────────────────────────────────────────┐
        │  每一拍（每 2 ms）执行：                  │
        └───────────────────┬─────────────────────┘
                            ▼
        ① 更新谷值：Signal < thresh 且 距上拍 > 3/5 IBI
             且 Signal < T   →  T = Signal
                            ▼
        ② 更新峰值：Signal > thresh 且 Signal > P  →  P = Signal
                            ▼
        ③ 判定心搏：Num > 250 ms
             且 Signal > thresh
             且 Pulse == false
             且 Num > 3/5 IBI          →  认为检测到一次心搏
                            ▼
           Pulse = true；PA5 点亮；IBI = Num；lastBeatTime = sampleCounter
                            ▼
           首拍丢弃 → 次拍用它填充 rate[10]（快速收敛）
                            ▼
           rate[] 左移一位，末位写入新 IBI
           runningTotal = 10 拍平均
           BPM = 60000 / runningTotal
           QS = true  → 通知主循环刷新显示与上传
                            ▼
        ④ 波谷判定：Signal < thresh 且 Pulse == true
             → Pulse = false；PA5 熄灭
               amp = P - T；thresh = amp/2 + T
               P = T = thresh
                            ▼
        ⑤ 失搏复位：Num > 2500 ms
             →  P = T = thresh = 512
                lastBeatTime = sampleCounter
                firstBeat = true；secondBeat = false
```

### 3.3 三个关键设计及其必要性

**（1）自适应阈值 `thresh = amp/2 + T`**

固定阈值在信号整体上移或下移时会失效。用上一拍的峰谷中点作为本拍阈值，
相当于让检测器"自己跟着信号走"，这是整套算法里最重要的鲁棒性来源。

**（2）二重脉抑制窗口 `Num > (IBI/5)*3`**

一次心搏后血管回弹会产生第二个小波峰。若不加限制，这个小波不但会被当成心搏，
还会让 IBI 骤减、BPM 骤增到 150+。用"上拍间期的 3/5 以内不重复触发"把它滤掉。

**（3）`Num > 250` 的高频噪声门限**

250 ms 对应 240 BPM，超过这个频率的起伏不是生理信号，直接忽略。

### 3.4 启动阶段处理

第一拍得到的 IBI 不可信（因为没有"上一次心跳"），所以：

- 第一拍：只清 `firstBeat`、置 `secondBeat`，**直接 return**，不计算 BPM；
- 第二拍：把 `rate[10]` 全部填成当前 IBI，让滑动平均快速进入合理区间；
- 之后：正常进入滑动平均流程。

这解决了"上电后 BPM 从 0 或者乱跳开始显示"的体验问题。

### 3.5 数值验证示例

假设稳定心率 75 BPM → 真实 IBI = 60000 / 75 = 800 ms。

- `Num > (IBI/5)*3` = 480 ms，即两次触发最小间隔 480 ms；
- 800 ms ≫ 480 ms，正常心搏不会被误抑制；
- 二重脉通常出现在主波后 200–300 ms，落在 480 ms 窗口内，被正确滤除。

## 4. 显示子系统

### 4.1 硬件形态

2.2 英寸 TFT 模组，分辨率 240 × 320，控制器 ILI9341，通过 4 线 SPI 通信，
但不使用 STM32 的硬件 SPI 外设，而是用普通 GPIO 模拟时序。

| 信号 | 引脚 | 代码宏 |
| --- | --- | --- |
| CS 片选 | PB4 | `LCD_CS_High/Low` |
| SCK 时钟 | PB3 | `LCD_SCK_High/Low` |
| SDI 数据 | PB5 | `LCD_SDI_High/Low` |
| DC 数据/命令 | PB1 | `LCD_DC_High/Low` |
| RESET 复位 | PB0 | `LCD_REST_High/Low` |

### 4.2 软件 SPI 实现

```c
void LCD_Writ_Bus(unsigned char com)
{
    for (unsigned char uci = 0; uci < 8; uci++) {
        if (com & 0x80) LCD_SDI_High(); else LCD_SDI_Low();  // 先放数据
        com = com << 1;
        LCD_SCK_Low();                                       // 上升沿采样
        LCD_SCK_High();
    }
}
```

命令/数据由 DC 引脚区分：`LCD_WR_REG()` 拉低 DC，`LCD_WR_DATA()` 拉高 DC。

### 4.3 显存寻址（理解 LCD 驱动的关键）

```c
void Address_set(x1, y1, x2, y2)
{
    LCD_WR_REG(0x2A);  // 列地址设置：写 x1 高/低字节、x2 高/低字节
    LCD_WR_REG(0x2B);  // 行地址设置：写 y1 高/低字节、y2 高/低字节
    LCD_WR_REG(0x2C);  // 进入显存写入模式，后续数据自动按窗口推进
}
```

在这个抽象之上，画点 = 1×1 窗口写 1 个像素；填充 = 大窗口循环写；显示汉字 = 逐行设定窗口后按位写像素。

### 4.4 字库与文字渲染

| 类型 | 取模方式 | 在 `font.h` 中的数组 |
| --- | --- | --- |
| ASCII 12×6 / 16×8 | 纵向取模，按字符索引 | `asc2_1206` / `asc2_1608` |
| 汉字 16×16 | 每字 32 字节 | `hanzi16` |
| 汉字 32×32 | 每字 128 字节 | `hanzi32` |

`LCD_ShowChar()` 提供两种模式：`mode=0` 显示背景色（不透明），`mode=1` 只画前景点（透明）。
`LCD_ShowNum()` 通过 `LCD_Pow()` 逐位取数，并自动跳过前导零。

### 4.5 波形刷新策略

```c
LCD_DrawLine(m*4, 300 - b*2/5, (m+1)*4, 300 - Signal*2/5);  // 与上一点连线
b = Signal; m++;
if (m >= 60) { m = 0; LCD_Clear(WHITE); ...重绘表头... }    // 清屏后重新开始
```

- 横坐标：每个采样点占 4 像素 → 60 点铺满 240 像素宽的屏幕；
- 纵坐标：`300 - Signal*2/5`，把 0–750 的采样值映射到 0–300 像素的绘图区；
- 幅度裁剪：`if (Signal >= 750) Signal = 750;` 防止越界画出屏幕；
- 刷新周期：60 点 × 2 ms = **120 ms 一屏**，即波形窗口为最近 120 ms。

> **可讨论的取舍**：120 ms 窗口只能看到约 0.15 个心动周期，视觉上"跳动感"强但看不出完整波形形态；
> 且每屏整屏清空会造成可见闪烁。改进方式见 `01-项目梳理.md` 第 6.2 节。

## 5. 通信协议

### 5.1 物理层

| 项 | 值 |
| --- | --- |
| 外设 | USART2（PA2 = TX，PA3 = RX，AF7） |
| 波特率 | 115200 bps |
| 帧格式 | 8 数据位 / 1 停止位 / 无校验（8N1） |
| 流控 | 无 |

### 5.2 应用层帧格式

```
<前缀字符><数值ASCII><CR><LF>

  'S'  原始波形采样值    例: S623\r\n
  'B'  心率 BPM          例: B75\r\n
  'Q'  心搏间期 IBI (ms) 例: Q800\r\n
```

| 特性 | 说明 |
| --- | --- |
| 分隔方式 | 前缀字符区分类型，CRLF 区分帧尾 → 上位机按行读取即可解析 |
| 发送时机 | `'S'` 每次主循环发送（约 50 Hz）；`'B'`/`'Q'` 仅在 `QS == true` 时发送 |
| 实现方式 | 重定向 `fputc` 到 `HAL_UART_Transmit`，直接用 `printf("%d\r\n", dat)` |

### 5.3 上位机侧伪代码

```python
for line in serial_lines:
    tag, value = line[0], int(line[1:])
    if tag == 'S': waveform.append(value)
    elif tag == 'B': bpm = value
    elif tag == 'Q': ibi = value
```

> 在 Processing / 串口示波器 / 自己写的 Python 脚本中均可直接使用，
> 这也是"硬件 + 上位机"完整链路的体现。
